# Security policy

Please do not report security vulnerabilities in a public issue. Use [GitHub's private vulnerability reporting](https://github.com/dunkymole/proto-contract/security/advisories/new) for this repository. Include the affected revision, runtime, and reproduction steps when available.

Proto Contract metadata is not authentication and must not be used to grant access. Deploy gRPC with appropriate transport security and authentication independently of contract checks.

The project is an early prototype. Security fixes target the latest revision until a supported release line is announced.
